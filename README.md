# Al Salam Theme - WordPress Theme

A modern, high-performance, fully customizable WordPress theme built specifically for Al Salam Pharmaceutical Company, designed to meet European GMP standards in digital presentation.

## Features

- **Modern Tech Stack**: Tailored CSS via Tailwind CSS workflow, swiper.js for carousels, GSAP for smooth animations.
- **Customizer Control**: Fully manageable via standard WordPress Customizer. Advanced accordion-style controls for easy management of Hero, About, Infrastructure, Products, Gallery, News, Testimonials, Marquee, and Footer sections.
- **Auto-Seeding Mechanism**: The theme includes an automated seeder to initialize the Customizer settings and create the required post types, categories, and dummy posts to match the original static template perfectly on first activation.
- **Custom Post Types**: Support for specialized `alsalam_product` and `alsalam_gallery` post types to structure the portfolio efficiently.
- **Page Metaboxes**: Detailed per-page header configuration and unique content tabs for specific templates (`page-about.php`, `page-contact.php`, `page-inquiry.php`, `page-join-us.php`).
- **Translation Ready**: Fully compatible with Polylang for multi-language (English and Arabic) support. Includes a robust string translation architecture.

## Installation

1. Copy the `alsalam-theme` folder into your `wp-content/themes/` directory.
2. In the WordPress admin, navigate to **Appearance > Themes** and activate "Al Salam Theme".
3. **Important**: Install and activate the **Polylang** plugin, configuring `en` and `ar` languages before proceeding.
4. Run the theme seeder (visit `wp-admin/?run_alsalam_seeder=1` and `wp-admin/?run_alsalam_customizer_seeder=1`) if you need to load the initial demo data, pages, posts, and settings. *Ensure you are logged in as an administrator.*

## Architecture

- **`assets/`**: Contains compiled CSS, JS, images, and fonts.
- **`includes/`**: Core logic including `customizer.php`, `setup.php`, `enqueue.php`, `page-metaboxes.php`, and AJAX form handlers.
- **`template-parts/`**: Modular template parts. The `front-page/` sub-folder contains all the individual sections of the homepage (Hero, About, Infrastructure, Products, Gallery, News, Testimonials, Marquee, Why Choose Us).

## Development & CSS Building

This theme uses Tailwind CSS for styling. If you need to add new dynamic classes or modify the core layout:

1. Make sure you have `tailwindcss` CLI installed.
2. Run the build process:
   ```bash
   npx tailwindcss -i ./assets/css/input.css -o ./assets/css/tailwind.css --watch
   ```
3. The `tailwind.config.js` is set up with a comprehensive `safelist` to ensure all dynamic classes generated by the Customizer are preserved in the final build.

## Customizer Guide

Navigate to **Appearance > Customize** to access the settings:

- **1. Global Settings**: Base colors, typography choices (English and Arabic fonts), and social media links.
- **2. Header settings**: Logo image, logo width, and call-to-action button settings.
- **3. Homepage Sections**: Expandable accordion panels to individually manage content, badges, titles, descriptions, and feature lists for every section on the front page.
- **4. Footer**: Title, copyright text, newsletter placeholder, and developer credits.

## Support

Developed strictly following WordPress Coding Standards. Uses `wp_enqueue_style/script`, `wp_ajax_*` with nonces and honeypots, and proper escaping/sanitization for all data handling.
